# Source provenance

The `google-docs` package was migrated from the original local authoring files
maintained by PedroAVJ. The original authoring folders remain preserved outside
this repository. Installed client caches were not used as canonical source.
The publication task retains the exact source paths and source hashes privately.

The first-party source, portable packaging changes, and original vector artwork
are released under the MIT license in `LICENSE`. No user credential, account
configuration, device snapshot, or operational screenshot is part of this
public package.
